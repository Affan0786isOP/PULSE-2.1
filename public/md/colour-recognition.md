## Evaluate selective attention with an interactive Stroop-style conflict task

### Cognitive Conflict and Interference

This task measures selective attention and cognitive control when processing competing information streams.

In Stroop-style conflict paradigms, automated reading processes can interfere with naming font ink colors when word meaning and ink color diverge.

### Assessment Structure

The test consists of 15 rounds containing a randomized mix of congruent and incongruent trials.

A prompt indicates whether to match the text meaning or the font color using five shuffled color choice buttons.

- 15 randomized stimulus rounds
- Dynamic matching rules (Word meaning vs Font color)
- Shuffled response options to prevent static spatial memorization

### Interference Cost and Accuracy

Scores summarize overall response latency, accuracy rates, and the interference cost representing latency differences between conflicting and congruent rounds.

### Display Considerations and Scope

Screen color calibration, ambient lighting, and display contrast influence color perception. This task is an educational cognitive benchmark, not a clinical test for color vision deficiency.

### Frequently Asked Questions

#### What is the Stroop Effect in colour recognition?

The Stroop effect occurs when reading the word involuntarily interferes with naming its ink color (e.g. the word RED printed in green ink). Resolving this conflict demands conscious cognitive control.

#### How is cognitive conflict cost calculated in PULSE?

PULSE computes the difference in average response latency between incongruent stimulus trials and congruent stimulus trials. A lower conflict cost indicates superior executive inhibition.

#### What false start threshold applies to colour recognition?

Because Stroop tasks involve word identification and response selection, responses registered under 80.01 milliseconds are rejected as anticipatory responses.

#### Can cognitive inhibition speed be trained?

Regular cognitive training and mindfulness can enhance selective attention and reduce distraction vulnerability, leading to more consistent conflict resolution.
