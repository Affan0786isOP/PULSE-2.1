## Assess spatial sequence memory through progressive 9-block tapping patterns

### Spatial Working Memory

Spatial working memory supports the temporary retention and sequential recall of visual locations in space.

It plays a fundamental role in navigation, spatial reasoning, and visual-motor coordination.

### Sequence Recall Mechanics

A 3x3 grid of 9 blocks highlights in a random sequence. Once playback concludes, tap the blocks in the identical order.

The sequence starts at length 2 and increases by one block with each successful round. Users start with 3 lives.

- 3x3 layout with 9 interactive blocks
- Sequence progression starting at level 1 with 2 blocks
- 3 lives before session concludes

### Progression and Span Score

Your final benchmark reflects the highest sequence span correctly completed before all 3 lives are exhausted.

### Scope and Strategies

Visual path chunking and pattern association can aid recall. This benchmark is provided for personal tracking and cognitive exploration, not neurological memory diagnosis.

### Frequently Asked Questions

#### What cognitive capacity does the Block Memory assessment test?

It evaluates visuospatial working memory and sequential recall, modeled after the clinical Corsi Block-Tapping test.

#### How does the difficulty scale across assessment levels?

The assessment begins with a 3-block sequence. Each successful replication increments the sequence length by one block, increasing working memory load.

#### When does the Block Memory test terminate?

The test concludes automatically after 3 cumulative unsuccessful sequence replications, recording your highest successfully completed sequence span.

#### Are Block Memory results scored by response time or sequence span?

Primary scoring is based on maximum block span and total correctly recalled sequences. Response latency is recorded as secondary telemetry.
