## Benchmark short-term digit recall capacity across increasing numerical sequences

### Digit Span Working Memory

Forward digit span measures the capacity of verbal working memory to temporarily retain and reproduce an arbitrary sequence of numbers.

It reflects storage capacity in short-term memory systems without long-term encoding.

### How the Assessment Operates

Sequences begin at level 1 with 3 digits and increase by one digit with each successful round.

Numbers appear on screen for a duration scaled to the digit count before clearing. Enter the sequence using the number pad or keyboard. You have 3 lives.

- Initial level starts with 3 digits
- Exposure time scaled to sequence length
- 3 lives before benchmark concludes

### Scoring and Level Advancement

Correct entries advance you to longer sequences, while incorrect submissions deplete lives. Your recorded score is the highest level achieved.

### Strategies and Scope

Chunking numbers into rhythmically grouped subsets can aid recall. This test is an educational benchmark, not a standardized psychometric IQ assessment.

### Frequently Asked Questions

#### What is the Digit Span memory test?

Digit span is an established neuropsychological benchmark measuring verbal and phonological working memory capacity (the phonological loop in Baddeleys model).

#### How long are digits displayed before recall?

Each number string appears on screen for a fixed duration proportional to digit length before input is prompted.

#### How does assessment termination work for Number Memory?

Similar to the block memory protocol, the assessment terminates immediately upon your third cumulative incorrect attempt, establishing your maximum digit capacity.

#### What is the average human digit memory span?

According to Millers classic psychological baseline, average human working memory capacity holds approximately 7 plus-or-minus 2 items in immediate recall.
