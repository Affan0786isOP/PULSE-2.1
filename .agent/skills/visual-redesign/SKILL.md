# Visual Redesign: Surgical Aesthetic Upgrade

Transforms generic, amateur, or machine-generated interfaces into premium, hand-crafted web experiences without breaking underlying application logic.

## When to Use & Phase Routing

Evaluate the current redesign phase and consult specialized references:

1. **Design Prescriptions (Phase 3)**
   - Typography scales, curated token palettes, component styling, atmosphere treatments, and motion rules.
   - **Reference File:** Read [prescriptions.md](references/prescriptions.md).

2. **Surgical CSS Rules & Surgery Execution (Phase 4)**
   - Non-destructive CSS overrides, surgical order, high-risk component preservation, and `data-reveal` hooks.
   - **Reference File:** Read [surgical-rules.md](references/surgical-rules.md).

3. **Anti-Slop Principles & Checkers**
   - Anti-slop doctrine, decision-before-generation rules, and visual honesty principles.
   - **Reference File:** Read [anti-slop-foundation.md](references/anti-slop-foundation.md).

## The Sacred Invariant
**APPLICATION LOGIC IS SACRED.** Never alter JavaScript/TypeScript state handling, form validation, event listeners, API contracts, or routing logic while executing a visual redesign. All improvements are achieved via CSS tokens and styling layers.
