# PULSE Assessment Marks

Five protocol-specific marks designed for the PULSE visual system.

| File | Protocol | Visual language |
| --- | --- | --- |
| `visual-reaction.svg` | Protocol 01 — Visual Reaction | precision reticle + response spike |
| `directional-choice.svg` | Protocol 02 — Directional Choice | four-way direction + central target |
| `colour-recognition.svg` | Protocol 03 — Colour Recognition | segmented signal ring + conflict cross |
| `block-memory.svg` | Protocol 04 — Block Memory | 3×3 spatial lattice + ordered path |
| `number-memory.svg` | Protocol 05 — Number Memory | modular digit-display sequence |

All marks use transparent backgrounds and the existing PULSE signal palette:
- Signal cyan: `#00F0FF`
- Stimulus white: `#F8FAFC`

They are intentionally vector-first and scalable for assessment cards, hero panels, favicons, and mobile UI.
